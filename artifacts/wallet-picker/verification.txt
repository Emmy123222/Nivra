Wallet choice modal — verification record

Baseline behavior
- Every Connect button called connectWallet(networkId).
- connectWallet selected listAvailableWallets()[0].
- A user with Lace and 1AM installed was never asked which connector to use.

Modified behavior
- Every existing Connect button now opens one global, accessible modal.
- The modal lists all detected compatible connectors and identifies Lace and 1AM.
- No connector connect() method runs before the user chooses.
- The selected wallet rdns is passed to the SDK; the SDK connects only that wallet.
- The modal supports Escape, backdrop close, a visible close button, mobile layout,
  detected API version, and a connecting-disabled state.
